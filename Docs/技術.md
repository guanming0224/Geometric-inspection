處理流程與使用的技術

1. ROI 裁切（Region of Interest）

lock_geometry.py:269
crop = frame[roi.y : roi.y + roi.h, roi.x : roi.x + roi.w]
只分析你框選的區域，減少背景干擾、也讓後面的邊緣統計只針對螺絲與平面的交界。ROI 是用 0~1 的比例存的，裁切前先換算成像素（normalised_region_to_lock_roi），所以換不同解析度的相機也適用。

2. 灰階轉換（Grayscale）

lock_geometry.py:273
gray = cv2.cvtColor(crop, cv2.COLOR_BGR2GRAY)
把 BGR 三通道轉成單通道亮度，後續的暗部判斷與邊緣偵測都在灰階上做。

3. 全域閾值二值化 → 暗部比例（Thresholding）

lock_geometry.py:274-277
dark = gray < dark_gray_threshold      # 預設 70
dark_ratio = dark.sum() / dark.size
用固定閾值把像素分成「暗 / 不暗」，算出 ROI 內暗像素的比例。原理是：螺絲和平面分離時中間會出現陰影或縫隙，暗部比例會上升。這是 dark 模式的判斷依據。

4. 高斯模糊（Gaussian Blur）

lock_geometry.py:279
blurred = cv2.GaussianBlur(gray, (5, 5), 0)
5×5 的高斯核去雜訊。Canny 對雜訊很敏感，先平滑可以避免金屬表面的刮痕、顆粒被當成邊緣。

5. Canny 邊緣偵測（Edge Detection）

lock_geometry.py:280
edges = cv2.Canny(blurred, 50, 150)
低閾值 50、高閾值 150 的雙閾值滯後偵測，輸出二值邊緣圖（邊緣 = 255，其他 = 0）。

6. 水平投影（Row Projection / Horizontal Profile）

lock_geometry.py:281
row_scores = edges.sum(axis=1)
把邊緣圖每一列的邊緣像素加總，得到一條一維曲線。曲線上的峰值就代表「這一列有一條明顯的水平線」— 螺絲底邊、平面表面都是水平邊緣，所以會在這條曲線上形成峰。這是整個方法的關鍵：把 2D 找線的問題壓成 1D 找峰。

7. 分區峰值搜尋（Peak Picking with Non-Maximum Suppression）

lock_geometry.py:249-260, 300-312
- 用 split_line_y 把投影曲線切成上半（找金屬邊緣）、下半（找平面基準線）
- 上半：strongest_edge_rows() 依分數排序，挑出最強的 N 條，並要求彼此至少相隔 4 列（min_distance）— 這是簡單的非極大值抑制，避免同一條粗邊被重複選到
- 下半：np.argmax 取最強的一列當基準線（若使用者沒手動指定 base_line_y）

8. 幾何量測（Gap Measurement）

lock_geometry.py:311-312
metal_edge_y = min(metal_edge_ys, key=lambda y: abs(base_line_y - y))
gap_px = abs(base_line_y - metal_edge_y)
取離基準線最近的金屬邊緣，兩者的垂直像素距離就是間隙 gap_px。

9. 規則判定（Rule-based Classification）

lock_geometry.py:319-336
- gap_px > gap_threshold_px → 分離
- dark_ratio > dark_threshold_ratio → 分離
- mode 決定用哪一個或兩者取 OR
- 紅線（red_line_y）：任何金屬邊緣越過紅線直接判分離，是一個硬性的位置限制
- 找不到邊緣或基準線 → unknown

10. 結果繪製（Overlay Drawing）

lock_geometry.py:397-430：cv2.rectangle、cv2.line、cv2.putText 把 ROI 框、分割線（灰）、紅線（紅）、金屬邊緣（橘）、基準線（黃）畫回原圖。

一句話總結

▎ ROI 裁切 → 灰階 → 固定閾值算暗部比例 ＋ 高斯模糊 → Canny → 水平投影找峰 → 量測兩條水平邊緣的像素距離 → 規則判定

這個方法的特性（給你放 README 或報告用）

- 優點：不需訓練資料、速度快（每幀只算 ROI 區域，可即時跑相機）、參數意義直觀、結果可解釋（畫出來的線就是判斷依據）
- 前提假設：螺絲邊緣與平面是水平的（投影是沿列加總，斜的邊緣會被分散掉）、光源穩定（固定閾值 70 與 Canny 50/150 都是對亮度敏感的）
- 主要限制：gap_threshold_px 是像素單位，會隨鏡頭距離與解析度變化，需要對每套設備校正；rotation_degrees 欄位存在但目前沒有被使用，所以還不支援旋轉的 ROI
